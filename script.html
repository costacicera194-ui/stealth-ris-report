Slide 03 01 概念内涵：雷达探测物理链路与信号博弈

0:30 - 1:15（45秒）｜字数预估：215字 | [换至 Slide 03] 激光笔定点右侧链路图，随后指示下方恒虚警检测波形 【逐字发言讲稿】 “谈隐身与伪装，必须首先立足雷达探测的物理本质。如图所示，雷达探测是一个严格的四步闭环：定向照射、目标感应散射、回波接收与信号判决。满足经典雷达方程，目标散射能力由雷达散射截面积 RCS（σ）唯一表征。 在电子对抗视域下，这本质是一场深层信号博弈： 一是信噪比（SNR）博弈：雷达要在高斯白噪声中提取微弱回波。隐身的终极目标，就是极力压缩目标 RCS，让回波功率降至恒虚警检测（CFAR）阈值以下，直接淹没在热噪声中； 二是信杂比（SCR）博弈：在地面、海面杂波背景下，雷达需辨识目标多普勒特征。伪装的核心，就是通过人工调控散射，让目标信号特征与环境杂波融为一体，使雷达无法提取有效航迹！” 【过渡串词提示】正因雷达对抗的博弈目标不同，我们在学术上绝不能将隐身与伪装混为一谈。

3.2 议题一【工程瓶颈与成本博弈】对抗问答与辩护逻辑

议题定位：【核心争论焦点】与直接多买几个 WiFi 路由器/AP 相比，智能电磁墙的本质瓶颈是什么？是否有商业与工程存在必要？

观众/同学高频质疑：“现在市场上一个 WiFi 7 路由器才两三百元，直接在房间多插一个路由器做 Mesh 组网，即插即用，成本很低。你们做这种复杂的智能超表面墙面，贴墙施工、外加主控板，成本和工程维护代价是不是反而高得多？它的本质瓶颈到底在哪？”

本组应答架构：（主答辩人：李源，郭向泓技术补充）

① 能耗与绿色 ESG 视角（李源答）：传统 Mesh 组网是有源中继方案，每个微基站/AP 都在持续消耗 15-30W 功率，且会向室内全向辐射射频底噪，造成严重的同频干扰与电磁污染；相比之下，智能电磁墙是纯无源相位相干导引，其电磁单元本身完全不发射新信号，整板仅在毫瓦级。在大规模智慧写字楼或医院部署中，年电费与碳排放可缩减 85% 以上，符合下一代绿色建筑的硬性标准。

② 频段演进与物理鸿沟（李源答）：在 Sub-6GHz 的 WiFi 频段，一堵砖墙穿透损耗仅 10-15 dB；但 5G 毫米波（28GHz/39GHz）乃至 6G 太赫兹频段，一堵 20cm 钢筋水泥墙损耗直奔 30-40 dB，信号完全被阻断，靠无线信号穿墙回传的 Mesh 路由器直接失效，必须重新拉光纤凿墙布线，施工成本数以万计。智能电磁墙以柔性薄膜形态贴于转角视距处‘拐弯绕射’，免除了光纤开槽布线的巨大工程代价。

③ 级联路径衰减 (d₁·d₂)² 的物理破局（郭向泓补充）：从电磁工程理论看，智能电磁墙最本质的瓶颈确实是双重级联路径损耗（Cascading Path Loss），即信号经历‘基站 → 电磁墙 → 终端’两次空间传播，其几何损耗正比于 (d₁·d₂)²，即四次方衰减。我们理论上有两大破解抓手：一是利用超表面的大规模阵列增益（相干叠加带来 N² 量级的功率反射增益）；二是工程上严格执行‘极近原则’（min(d₁, d₂) 最小化策略），将电磁墙紧贴基站侧或紧贴盲区终端部署，使菲涅尔近场聚焦效应占主导，从而将四次方衰减退化为接近单次自由空间衰减。

3.3 议题二【无源感知与信道状态获取】硬核技术方案应答

议题定位：【核心争论焦点】智能电磁墙没有射频基带收发链路，怎么“看”到移动设备在哪里？如何实时获取信道状态信息（CSI）并精确对准波束？

老师/评委尖锐质询：“你们强调智能电磁墙是‘近零功耗无源表面’，这意味着它上面没有昂贵的高频射频基带收发芯片，没有完整的 A/D 采样链。既然它是个‘瞎子’，它怎么知道移动中的手机在哪里？怎么实时获取信道状态信息（CSI）并把波束准确打向终端？”

本组应答架构：（主答辩人：郭向泓，胡淇理论补充）

① 极低开销稀疏射频传感架构（郭向泓答）：目前学界最成熟的工程路线是非对称稀疏射频传感架构：在包含数千个纯无源反射单元的电磁墙周边，仅点缀部署小于 1%（如 4 到 8 个）超低功耗微型接收单元。这些单元不参与数据通信解调，仅采集导频信号的互相关相位差，通过超分辨 MUSIC 或 ESPRIT 算法在毫秒内反演来波方向角（DOA），以极小的硬件成本和微瓦级功耗赋予墙面‘听声辨位’的感知能力。

② 盲码本轮询与终端 ACK 极值反馈机制（郭向泓答）：如果要求 100% 纯无源，我们采用‘基站-终端双端协同闭环’。基站预设离散 DFT 波束赋形码本，电磁墙控制器以 5-10 毫秒的高速依次扫掠离散相位分布；手机终端无需计算复杂信道矩阵，只需在检测到信号峰值时通过常规信令向基站回传一个标量 ACK（如 CQI/RSSI 极大值指示）。基站据此通过低速总线锁定电磁墙的编码序列，实现‘免信道估计的波束极值追踪’。

③ 环境反向散射感知与基站侧算力卸载（胡淇补充）：从信息超材料物理机制看，电磁墙自身还可以对入射载波施加微小的低频占空比通断键控（OOK），构造反向散射信标，由基站测算反射多径特征，在基站算力侧完成‘盲解耦’。这种感知计算全部由有源基站侧承担，确保电磁墙维持近零功耗的本色。

3.4 议题三【反向思辨：民用电磁隐私防御】升华讨论与哲学反思

议题定位：【核心争论焦点】当建筑墙面具备高维控波能力，会不会被攻击者利用造成安全危机？普通民众是否也需要一件“民用电磁隐身与伪装衣”？

观众/同学前瞻提问：“智能电磁墙不仅能导引通信波束，还能利用毫米波感知室内微动甚至心跳。这是否意味着如果电磁墙被黑客入侵，或者外部有恶意雷达窥探，我们室内所有人的一举一动都会被‘透墙看光’？当建筑具备控波能力，会不会造成严重的隐私危机？”

本组应答架构：（主答辩人：胡淇，李源、童靖凯升华总结）

① 深刻揭示通感一体的物理层隐私困境（胡淇答）：在即将到来的 6G 通感一体化（ISAC）时代，高频毫米波与太赫兹具备亚毫米级的穿透成像分辨率，攻击者无需进入房间，仅用一台便携式微动雷达在室外发射电磁波，就能根据回波中的微多普勒频移，穿墙探测室内有几个人、在什么位置，甚至通过心率步态特征识别出个人身份。在这个维度下，传统的软件加密和防火墙在物理层电磁探测面前完全失效！

② 逆向重构：将军事隐身与伪装技术逆向民用（胡淇答）：但这也正是电磁波调控技术最具魅力的地方——能攻者亦善守！智能电磁墙在平时是赋能通信的‘增强中继’，而在隐私敏感时刻，只需一键切换工作状态，即可反向应用军事隐身与伪装原理： 1. 民用电磁隐身模式（吸波黑洞）：利用电磁墙的阻抗可调特性，将表面阻抗与自由空间阻抗（377 Ω）严格匹配，瞬间化身为宽带吸波体，将外部窥探的雷达波及室内外泄的射频信号全额吸收耗散，构筑物理层‘电磁静默保密室’； 2. 民用电磁伪装模式（微多普勒混淆）：如果不希望完全屏蔽信号，超表面单元可施加伪随机相位时变调制，在散射波中人为注入人工杂波噪声，将人体的微弱生理多普勒频移彻底掩盖；甚至可以预设编码‘凭空伪造出有人走动的散射特征’，在空房间里实现防盗声东击西伪装！

③ 军民两用技术的终极哲学闭环（童靖凯升华总结）：大家可以看到，我们从军事电子对抗的‘雷达隐身与伪装’出发，跨界走向了民用通信的‘波束导引与覆盖’；而在面对民用隐私安全挑战时，我们又自然回到了‘电磁隐身与伪装’。这雄辩地证明：电磁波调控技术在物理本质上是完全同源且价值中立的自由度。作为新时代的电子信息学子，我们需要掌握控波的物理规律，不仅在战场上筑牢国防盾牌，更在民生中守护人民的连接与隐私！

第四部分：授课教师高难度“灵魂拷问”专项预案与硬核答辩锦囊

针对授课教师可能在理论深度与数学模型上进行的深水区质询，本组特备以下硬核防线：

拷问 1：罗扎诺夫极限（Rozanov Limit）在理论上真能被智能超表面突破吗？数学机理是什么？

【指定主答辩人】胡淇（理论答辩）

【硬核理论应答】罗扎诺夫积分不等式原始形式为 |∫ln|Γ|dλ| ≤ 2π²μs·d，其推导基于复分析 Cauchy 定理与因果律决定的 Kramers-Kronig 关系，铁律前提是：系统必须是线性时不变（LTI）无源体系。 传统超材料本构参数静态不变，受禁锢于 LTI 框架绝不可破；而智能可重构超表面引入了高频时间调制（Time Modulation），反射系数具有周期时变特性 Γ(t)=Γ(t+T)，系统在数学底层打破了‘时不变性’，在频域激发出无穷阶边带谐波。因此，智能超表面不是在传统框架内违背热力学，而是通过升维至时变非线性系统，跳出了罗扎诺夫极限的适用域！

拷问 2：级联路径损耗正比于 (d₁·d₂)²，远距离信号衰减极大，如何从物理上论证工程可行性？

【指定主答辩人】郭向泓（工程答辩）

【硬核理论应答】自由空间下 RIS 接收功率满足 Pr ∝ Pt·(λ⁴·σ_RIS) / [(4π)³ (d₁ d₂)²]，乘积四次方确实恶化严重。但本组有三大理论支撑： 1. 阵列相干增益（N² 标度律）：RIS 包含 N 个微元，相位对齐相干叠加提供 N² 功率增益。N=10⁴ 时阵列增益高达 80 dB，足以弥补二次级联衰减； 2. 辐射近场（Fresnel Zone）有效衰减退化：根据瑞利距离判据 2D²/λ，毫米波下（D=1m, 28GHz）近场距离达 180 米，室内 5-10 米完全属于近场准直波束，衰减规律退化为接近单次自由空间衰减 (d₁+d₂)²； 3. 极近部署原则：数学上 min(d₁, d₂) 最小化策略，将 RIS 紧贴基站或紧贴用户盲区部署，大幅压低几何乘积损耗。

拷问 3：隐身与伪装在数学模型和雷达判决准则上的严格数学表征是什么？

【指定主答辩人】胡淇（理论答辩）

【硬核理论应答】在 Neyman-Pearson 统计判决框架下： • 隐身数学本质：在给定虚警概率 Pfa 下，极力最小化检测概率 Pd（min Pd = ∫p(y|H₁)dy → Pfa），通过压缩后向散射截面积 σ，使 H₁ 假设下的检验统计量分布完全坍缩重叠至 H₀ 噪声分布，让雷达丧失判别自由度； • 伪装数学本质：扰乱多维假设分类器的混淆矩阵（Confusion Matrix），操控微多普勒、极化矩阵等特征向量 f 的后验概率分布，使 P(C_真|f) → Min，而 P(C_假|f) 或 P(C_杂波|f) → Max。两者在统计假设检验的数学目标完全不同！

拷问 4：超表面在面对宽带信号和大角度入射时，微带贴片单元的相位色散与阻抗失配如何解决？

【指定主答辩人】郭向泓（工程答辩）

【硬核理论应答】大角度入射（>60°）导致空间波阻抗分裂为 η₀/cosθ（TE波）与 η₀cosθ（TM波），贴片谐振频移且互耦加剧。工程对策包括： 1. 紧耦合超表面拓扑（TCM）：利用单元重叠电容补偿斜入射阻抗漂移，展宽角度稳定性至 ±60°； 2. 旋转对称各向同性超薄单元：单元周期 < λ/10，消除极化敏感度； 3. 前向非规则相位补偿矩阵：主控在决策编码时调用包含角度-频率校准补偿表的码本矩阵，在数字域进行自适应预失真校正。

拷问 5：号称“零功耗”，但 FPGA 控制器与偏置电路也有能耗，如何客观评价？

【指定主答辩人】李源（应用答辩）

【硬核理论应答】我们在学术报告中严格使用‘近零功耗（Near-Zero Power）’，而非绝对零功耗。 传统中继放大器的功耗瓶颈是有源射频功率放大器（PA），单台数十瓦；而 RIS 免除了高功耗射频功放链，功耗仅来自二极管微安级直流偏置与 MCU 翻转。以 1024 单元的 PIN 板卡为例，静态功耗仅约 1.5W；若换用变容二极管或压电 MEMS，更降至毫瓦级（降低 85% 以上）。此外，大面积物理孔径天然支持射频能量捕获（SWIPT），可从环境 WiFi 信号中自供电运营。
